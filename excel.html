Ringkasan Rumus Excel

Materi singkat untuk persiapan UAS Aplikasi Komputer

1. Rumus Dasar

Beberapa rumus berikut sering digunakan untuk mengolah data angka di Microsoft Excel.

AB
1Nilai Tugas80
2Nilai UTS75
3Nilai UAS90

A. SUM

Digunakan untuk menjumlahkan seluruh nilai dalam suatu range.

=SUM(B1:B3)

Hasil: 245

B. AVERAGE

Digunakan untuk menghitung nilai rata-rata.

=AVERAGE(B1:B3)

Hasil: 81,67

C. MAX

Digunakan untuk mencari nilai terbesar.

=MAX(B1:B3)

Hasil: 90

D. MIN

Digunakan untuk mencari nilai terkecil.

=MIN(B1:B3)

Hasil: 75

2. Fungsi IF

Rumus IF digunakan untuk menentukan hasil berdasarkan kondisi tertentu.

=IF(Kondisi, "Jika Benar", "Jika Salah")

Contoh: Jika nilai pada sel B2 lebih dari atau sama dengan 75, maka hasilnya "LULUS". Jika kurang dari 75, maka hasilnya "REMEDIAL".

=IF(B2>=75,"LULUS","REMEDIAL")

3. IF dengan LEFT, MID, dan RIGHT

Ketiga fungsi ini digunakan untuk mengambil sebagian karakter dari sebuah teks dan sering dipadukan dengan IF.

A (Kode)B (Keterangan)
1MKS-01-M...

A. LEFT

LEFT digunakan untuk mengambil karakter dari bagian kiri teks.

Contoh: Jika tiga karakter pertama adalah "MKS", maka hasilnya "MAKASSAR".

=IF(LEFT(A1,3)="MKS","MAKASSAR","LUAR KOTA")

B. MID

MID digunakan untuk mengambil karakter dari posisi tertentu di dalam teks.

Format penulisan:

MID(Teks, Posisi_Awal, Jumlah_Karakter)

Pada contoh kode MKS-01-M, angka "01" berada pada karakter ke-5 dan terdiri dari dua karakter.

=IF(MID(A1,5,2)="01","Angkatan 1","Angkatan 2")

C. RIGHT

RIGHT digunakan untuk mengambil karakter dari bagian kanan teks.

Jika karakter terakhir adalah "M", maka hasilnya "Male". Selain itu hasilnya "Female".

=IF(RIGHT(A1,1)="M","Male","Female")

4. VLOOKUP dan HLOOKUP

Kedua fungsi ini digunakan untuk mengambil data dari tabel referensi berdasarkan nilai tertentu.

Perbedaan:
  • VLOOKUP digunakan jika tabel referensi tersusun secara vertikal.
  • HLOOKUP digunakan jika tabel referensi tersusun secara horizontal.

A. VLOOKUP

Format penulisan:

=VLOOKUP(Sel_Kode,Tabel_Referensi,Nomor_Kolom,FALSE)

Contoh:

=VLOOKUP(A2,$D$2:$E$5,2,FALSE)

Gunakan tombol F4 agar referensi tabel menjadi absolut sehingga tidak berubah ketika rumus disalin.

B. HLOOKUP

Format penulisan:

=HLOOKUP(Sel_Kode,Tabel_Referensi,Nomor_Baris,FALSE)

Contoh:

=HLOOKUP(A2,$D$10:$G$12,3,FALSE)
